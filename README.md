# GKM TI Politeknik Negeri Jember

Sistem berbasis web yang dikembangkan untuk mendukung kegiatan Gugus Kendali Mutu (GKM) pada Jurusan Teknologi Informasi Politeknik Negeri Jember. Aplikasi ini digunakan untuk mengelola proses penilaian kualitas jurusan, termasuk pengolahan data, penyusunan instrumen penilaian, serta monitoring hasil evaluasi secara terstruktur.

---

## Deskripsi Sistem
Aplikasi ini berfungsi sebagai platform terpusat untuk melakukan penilaian dan pengelolaan data mutu akademik. Sistem membantu proses evaluasi menjadi lebih terorganisir, transparan, dan mudah diakses oleh pihak terkait.

---

## Fitur Utama
- Sistem penilaian kualitas jurusan  
- Manajemen penilaian dosen  
- Pengelolaan soal dan instrumen evaluasi  
- Dashboard monitoring hasil penilaian  
- Manajemen data pengguna (admin, dosen, dan pihak terkait)  
- Pengolahan dan penyimpanan data penilaian  

---

## Teknologi yang Digunakan
- Backend: Laravel  
- Frontend: Blade, CSS, JavaScript  
- Database: MySQL  

---

## Peran dalam Pengembangan
- Mengembangkan backend dan frontend sistem  
- Membangun modul penilaian dan manajemen data  
- Mendesain antarmuka pengguna (UI/UX)  
- Memimpin tim dalam proses pengembangan  

---

## Catatan
Sistem ini merupakan proyek privat yang dikembangkan untuk kebutuhan internal Gugus Kendali Mutu (GKM) Jurusan Teknologi Informasi Politeknik Negeri Jember.
